## 7. Assumptions

1. Drawing units: $INSUNITS = 6 (metres) in every structural file; confirmed against dimension values (e.g. 0.20 = 200 mm column).
2. Storey height BS: +0.30 (GR T.O.S) - -4.10 (FDN T.O.F) - 0.250 (GR slab thickness) = 4.150 m - NOT YET CONFIRMED by user
3. Storey height GR: +4.70 (L1 T.O.S) - +0.30 (GR T.O.S) - 0.250 (L1 slab thickness) = 4.150 m - NOT YET CONFIRMED by user
4. Storey height L1: +8.45 (PH T.O.S) - +4.70 (L1 T.O.S) - 0.250 (PH slab thickness) = 3.500 m - NOT YET CONFIRMED by user
5. Storey height PH: +12.40 (TOR T.O.S) - +8.45 (PH T.O.S) - 0.250 (TOR slab thickness) = 3.700 m - NOT YET CONFIRMED by user
6. Level FDN: several T.O.F values are equally frequent ([-4.1, -3.9, -3.5, -3.3]); the lowest was used.
7. Level L1: several T.O.S values are equally frequent ([4.7, 4.85]); the lowest was used.
8. Level TOR: several T.O.S values are equally frequent ([12.4, 12.9]); the lowest was used.
9. Column height basis: to_slab_soffit (configurable in Settings).
10. Beam depth basis: below_slab; families whose schedule depth excludes the slab: Tie beam.
11. Slabs measured over beams (gross zone area less shafts/openings); beams measured below the slab to avoid double counting.
12. Footing and column volumes use the drawn geometry; schedule sizes are used as an independent cross-check.
13. Blinding thickness 100 mm from drawing note (12 occurrences on S-FD.dxf).
14. Tie-beam depth = largest vertical dimension on the 'TYPICAL SECTION THROUGH T.B.n' detail; width from the plan.
15. Pedestal size note '500X500X500 MM' interpreted as length x width x height.
16. RC wall height = storey height of the floor; door/window openings in walls are not deducted.
17. Slab IDs, raft IDs and residual-zone IDs are system-generated - the drawings do not number them.
