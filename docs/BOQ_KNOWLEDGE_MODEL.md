# Static Group BOQ Knowledge Model

Version 1.0 · 57 canonical items · source: `config/knowledge/static_boq_model.json` (generated by `tools/write_knowledge_doc.py` – edit the JSON, not this page).

The model generalises Static Group's BOQ lines across projects. Each canonical item records how the line is worded (match patterns), its unit, the drawings that hold its information, the measurement method and formula, its dependencies, and how far it can be automated today. One drawing element can feed several items (e.g. a ground beam → ground-beam concrete, blinding, waterproofing, backfill deduction); the engine keeps the element→item links for evidence.
